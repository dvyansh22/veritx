Phase 02: Master Key Generation (HMAC-SHA512)

Post-Quantum One-Way Primitive

The root master key is derived using HMAC-SHA512 with the canonical constant salt "Bitcoin seed".

Post-Quantum Resistance Core:
HMAC-SHA512(key="Bitcoin seed", data=seed) = IL (32B Private Key) || IR (32B Master Chain Code)
Because SHA-512 is a hash function, it retains 256 bits of security against quantum Grover searches ($2^{256}$ operations).

Phase 03: HD Child Key Derivation Walk (CKDpriv)

Iterative Child Derivation

The guest walks the derivation path hop-by-hop. Hardened indices pass 0x00 || ParentKey || Index to HMAC-SHA512.

Child Key Derivation Formula:
Hardened: HMAC-SHA512(ChainCode, 0x00 || ParentPriv || Index) = IL || IR
ChildPriv = (IL + ParentPriv) mod n, ChildChainCode = IR
